# Architecture Decision Records

An index of every ADR in this repository, oldest first. Each row is a one-clause summary of what
was decided, not the rationale — read the ADR itself for that.

Numbers are stable identifiers, not a dense sequence — a retired ADR's number is never reused, so
gaps in the table (0009, 0012, 0015, 0016) are expected, not missing files.

| ADR                                                                                                       | Status                                                         | What it decided                                                                                                                                                                        |
| --------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [0001 — Version tombstones](0001-version-tombstones.md)                                                   | Accepted (2026-07-19)                                          | Version blobs are purged by per-tier retention policy; version rows survive as tombstones so comments and anchors stay truthful without the blob.                                      |
| [0002 — Handover workflow](0002-handover-workflow.md)                                                     | Accepted (2026-07-17); §C decisions 2–3 superseded by ADR 0007 | Sign-off status is derived (never stored) from append-only approvals with an org-configurable soft/hard gate; suggested edits ship as a comment subtype.                               |
| [0003 — Rendered diff and review signals](0003-rendered-diff-and-review-signals.md)                       | Accepted (2026-07-17)                                          | Version diffs are computed server-side in the domain layer and rendered by a transient Compare surface, alongside comment search, mentions, and a signal-budget UX pass.               |
| [0004 — Public Docs Hub](0004-public-docs-hub.md)                                                         | Accepted (2026-07-18)                                          | The public, unauthenticated publishing surface lives entirely outside the tenant/RLS model — a separate table, a separate DB role, snapshot-copy publish.                              |
| [0005 — Test infrastructure and session/CSRF policy](0005-test-infrastructure-and-session-csrf-policy.md) | Accepted (2026-07-20)                                          | Integration tests run against a real, ephemeral-per-run local Postgres (`createTestDb`) instead of Testcontainers/LocalStack, plus the session-duration and CSRF mechanism.            |
| [0006 — Zero-downtime deploys and safe migrations](0006-zero-downtime-deploys-and-safe-migrations.md)     | Accepted (2026-07-20)                                          | Every migration is either expand or contract, never both, and contract only ships once nothing reads the old shape; a deploy provides health-gated, rollback-capable rollout.          |
| [0007 — Deferred suggestion materialization](0007-deferred-suggestion-materialization.md)                 | Accepted (2026-07-26)                                          | Accepting a suggested edit is metadata-only; materialization is detected lazily by the re-anchor pipeline when a later real edit exactly matches the proposal.                         |
| [0008 — Grantable edit rights](0008-grantable-edit-rights.md)                                             | Accepted (2026-07-30); amended by ADR 0014                     | An `edit` share grant buys exactly `uploadNewVersion` and nothing else; guests are structurally barred from ever holding it, three separate ways.                                      |
| [0010 — Rate-limiter test infrastructure](0010-rate-limiter-test-infrastructure.md)                       | Accepted (2026-08-04)                                          | Rate-limiter tests run against a real local Valkey (Homebrew, no container), mirroring ADR 0005's Postgres approach, plus the limiter's CAS/clock design.                              |
| [0011 — Upload content validation and size cap](0011-upload-content-validation-and-size-cap.md)           | Accepted (2026-08-04)                                          | Four content-policy checks land in a single pure domain function, and the upload size cap is set at 500KB.                                                                             |
| [0013 — MCP OAuth: protected resource only](0013-mcp-oauth-protected-resource.md)                         | Accepted (2026-08-09)                                          | No new authorization server is built; `packages/mcp` gains a second Bearer-token path that verifies AuthKit-issued JWTs, alongside the existing API-key path.                          |
| [0014 — Share permission and project grants](0014-share-permission-and-project-grants.md)                 | Accepted (2026-08-13)                                          | A new `share` permission rung buys only grant creation/revocation, capped at the grantor's own held level; `edit` inherits `share` by lattice; project-level share grants become real. |
